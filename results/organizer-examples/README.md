# Результаты на семи деталях организаторов

Физически ничего не печаталось: время и расход материала это оценка слайсера.

## Как получены результаты

- **Окружение.** Windows 10, STE Slicer 7.10.12 с плагином AI Assistant, принтер Stereotech Hybrid 530 V5.2.4 (`hte530v5.2.4`), лицензия на режимы 5D применена. Модель Qwen (`dashscope/qwen3.8-flash`).
- **Код.** Бэкенд взят из портативной сборки `AIAssistant-portable.zip` (SHA-256 начинается с `296f096b…`), установленной в слайсер. Она **не совпадает побайтно ни с одним закоммиченным состоянием**: она собрана раньше итоговой версии, логика подбора и нарезки той же линии. Таймаут нарезки в плагине поднят до 1200 с, как в итоговой версии, в остальном плагин не менялся.
- **Запуск.** Детали 1, 2, 3, 4, 6 и 7 прогнаны скриптом `scripts/eval_pipeline.py` через HTTP API отдельным экземпляром бэкенда; на уточняющие вопросы ассистента скрипт отвечает «Подтверждаю, продолжай», по одному заходу на деталь. Деталь 5 (Wilo) прогнана вручную через веб-интерфейс; слайсер в этот момент был запущен пользователем.
- **Один заход.** Каждая итоговая папка это последний успешный прогон детали. Модель недетерминирована, повторный прогон даст другие параметры и другое время.

## Что нужно знать при оценке

- **Шаг OpenSCAD в 5D.** Для режима 5D слайсер считает пересечение детали со вспомогательной сеткой через `openscad.exe`. В прогонах он вёл себя так: у детали 2 он завершился с кодом 1 через ~3 с, у детали 5 (Wilo) с кодом 1 через ~2 мин 25 с, у детали 7 отработал без ошибок. При ошибке слайсер продолжает нарезку без этого шага. Что это значит для геометрии 5D, независимо проверить нельзя; на простой задаче OpenSCAD 2021.01 из комплекта исправен. Ошибка остаётся в слайсере, плагин на неё не влияет.
- **Время печати.** Две оценки: по шапке G-code (`;TIME`) и по `getPrintInformation` слайсера, которую приводит отчёт ассистента. У 3D-деталей они совпадают, у 5D расходятся на 3–12 % (см. `run.json`, поля `gcode_print_time_s` и `pipeline_print_time_s`). В таблице выше время по G-code.
- **Что проверено в G-code.** Слои, пустые слои (нет ни в одном файле), внешняя стенка в слоях детали, габариты против STL (совпадают), водонепроницаемость STL. Это проверка файла, а не печати: прочность, качество поверхности и геометрию траекторий в 5D по тексту G-code оценить нельзя.
- **Окружение слайсера.** При запуске слайсера не из ярлыка (без рабочей папки установки) OpenSCAD не находится, а после 5D-нарезки 3D-нарезка в той же сессии слайсера зависает (в итоговой версии это исправлено). Для этих результатов слайсер перед 3D-деталями перезапускался; все итоговые файлы получены после проверки, что движки запущены.
- **Прогоны, не вошедшие в набор.** До итоговых были неудачные или некорректные: нарезка не укладывалась в таймаут 300 с (Wilo), модель вернула ответ не по схеме на первом этапе, 3D зависла после 5D, 5D считалась без OpenSCAD из-за запуска слайсера без рабочей папки. Их результаты удалены и в набор не включены.
