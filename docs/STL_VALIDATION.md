# Проверка анализатора STL

Проверено локально 23 октября 2026 года на macOS, CPython 3.11.15. Цель: CLI принимает файл или папку, формирует отчёты, обнаруживает заданные дефекты и сохраняет исходные STL неизменными. Задачи и проверки выведены из запроса пользователя, отдельного исходного плана не было.

## Автоматические проверки

Сначала добавлены тесты; первый запуск завершился `ModuleNotFoundError: No module named 'src.mesh_analysis'` — отсутствовала запрошенная реализация. После реализации и добавления необходимых зависимостей получен первый зелёный прогон: 13 тестов. При проверке исходников Trimesh обнаружено, что `split` может заполнять отверстия; явно задано `repair=False`. Дополнительно проверены несогласованный обход граней, нечисловые координаты, лимиты, плоская и полностью схлопнутая сетки.

Финальная команда:

```sh
/tmp/mosprom-stl-venv/bin/python -m pytest -q --cov=src --cov-report=term-missing --cov-fail-under=80
```

Результат: **19 passed**, покрытие анализатора **95,96%**. Проверка Ruff (`--isolated --select E4,E7,E9,F,I`) и `git diff --check` проходят.

Дополнительная команда `python tests/verify_stl_reports.py artifacts/stl-analysis` подтвердила **7/7**: SHA-256 исходников совпал, число треугольников, габариты, площадь, интеграл объёма, число компонент и счётчики граничных/неманифолдных рёбер согласуются с независимым чтением бинарного STL без Trimesh. Полные локальные результаты находятся в `artifacts/stl-analysis/`: `SUMMARY.md`, `index.json`, `verification.json` и отдельные JSON/Markdown/PNG. Они исключены из Git. Данные не копируются в тестовый репозиторий; CI использует генерируемые аналитические модели.

## Оставшиеся ограничения

Самопересечения, вложенность и пересечения оболочек, манифолдность в вершинах и физическая пригодность не проверены. Минимум выборочных хорд не равен доказанной минимальной толщине стенок. Проверка на семи моделях не доказывает корректность на всех возможных STL.

Актуальный CI выполняет полный набор в Docker на Ubuntu, включая проверки анализатора. Как запустить проверки, описано в [руководстве первого этапа](STAGE1_IMPLEMENTATION.md#проверки). Установка и интеграция со STE Slicer на Windows пока не проверены.
