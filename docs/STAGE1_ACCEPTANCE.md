## Воспроизводимый прогон

```bash
docker compose -f compose.test.yaml up --build --abort-on-container-exit --exit-code-from tests
```

Настоящий PostgreSQL 18, API, worker, файловые процессы и Chromium. Только внешний Qwen заменён управляемым тестовым HTTP-сервером. Тестовый сервер не используется при обычном запуске. Итоговые числа последнего прогона приведены в конце документа.

Артефакты сохраняются в `artifacts/compose`: лог pytest/покрытие в общем логе запуска, `performance.jsonl`, `playwright/results.json`, HTML-отчёт `playwright-report/index.html`, скриншоты и traces падений. Локальный полный лог — `artifacts/compose-test-final.log`. Тяжёлые входные STL и результаты намеренно не добавляются в Git; CI прикладывает отчёт как артефакт запуска.

## Производительность и ограничения измерений

Оборудование локальных измерений: Apple M3 Pro, 18 GiB RAM, macOS 26.5 arm64; контейнерные проверки — Linux aarch64 Docker Desktop на той же машине.

- Семь реальных STL с 128 выборочными лучами и PNG: 32.92 секунды суммарно; пик RSS процесса около 1.36 GiB. Это измерение пакета, не обещание лимита памяти на любой файл в 2 млн граней.
- Синтетические сферы 80/320/1280/5120/20480 треугольников: геометрия без лучей примерно 0.03–0.26 секунды, пиковые отслеживаемые Python-выделения 0.26–40.5 MB. Это не полный RSS процесса.
- Выборка событий при истории 0/1/10/100/1000 записей: два SQL-запроса и не более 100 событий. Проверка текущей ревизии и список чатов не возвращают большой `card` из JSONB.
- Группировка требований измеряется на 100–10000 элементах; используются хеши/словари, сортировка и дедупликация, без полного попарного сравнения.
- Пять параллельных health-запросов проходят во время каждого из пяти типов длительных операций; порог проверки — 2 секунды на пакет. Фактические значения каждого прогона записаны в JSONL.

Это контроль роста затрат и отзывчивости, а не нагрузочная сертификация промышленного сервера. Предельные 256 MiB/2 млн треугольников ограничены до анализа, но отдельный стресс-прогон файла максимально разрешённого размера не выполнялся.
