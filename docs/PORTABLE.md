# Портативная версия

Приложение работает одним процессом на SQLite и ставится как плагин STE Slicer: распаковать архив в папку плагинов и открыть слайсер. Docker, Postgres и отдельные запуски не нужны. В архиве ассистент с инструментами, несколько проектов в одном чате, очередь сообщений и настройки модели в окне чата.

## Установка для жюри

1. Скачайте `AIAssistant-portable.zip` и закройте STE Slicer. Если в папке плагинов уже есть `AIAssistant` от прежней сборки, удалите её: база прежней схемы не обновляется.
2. Распакуйте архив так, чтобы получилась папка `%APPDATA%\steslicer\7.10\plugins\AIAssistant` (путь открывается через «Справка → Показать папку конфигурации», подпапка `plugins`).
3. Запустите STE Slicer и выберите «AI Assistant → Открыть StereotechAI». В браузере откроется чат.
4. При первом запуске чат попросит адрес API, модель и ключ.

Первый запуск занимает до минуты: создаётся база и загружаются знания. Если чат не открылся, причину смотрите в `AIAssistant\runtime\data\logs\backend.log`.

## Где результат

Каждый готовый расчёт кладётся в свою папку `Documents\STE_AIAssistant\Результаты\<деталь>`. Имя папки это название детали, которое дал ассистент. Если такая папка уже есть, к имени добавляется номер, например `Шестерня (2)`, и прежний результат не меняется. Новая деталь в том же чате тоже получает свою папку.

В папке лежат
- `project.3mf`, проект STE Slicer со всеми настройками;
- `result.gcode`, G-code этого проекта;
- `chat_01.png` (и `chat_02.png` и дальше, если переписка длинная), картинка переписки по проекту: что спросил ассистент, что ответил пользователь, итоговый отчёт;
- `report.md`, итоговый отчёт текстом.

Если нарезки не было (слайсер не запущен, параметры не подобрались), в папке будут только переписка и отчёт с причиной. Путь к общей папке показан в панели «Файлы проекта», путь к папке проекта в итоговом отчёте.

Режимы 5D режет внешняя программа слайсера, ей нужна лицензия. Её получают один раз на компьютер: начать в слайсере нарезку в 5D, скопировать код из окна ATSS, ввести его на странице кейса (вкладка STE Slicer), запустить скачанный `steslicer_license.reg` и перезапустить слайсер. Лицензия действует 10 дней.

## Как устроено

Слайсер встраивает Python 3.5, а наше приложение требует 3.11. Поэтому плагин (3.5) запускает рядом наше приложение на своём Python 3.11, лежащем в той же папке.

```
AIAssistant\
  plugin.json, AIAssistant.py, agent\     плагин, Python 3.5, только стандартная библиотека
  runtime\
    python\                               портативный Python 3.11 с установленными пакетами
    app\                                  src\backend (с промптами агентов и таблицами подбора), src\mesh_analysis.py, knowledge\, src\web\dist
    data\                                 app.db (SQLite), model.json, загрузки, артефакты, logs\
```

1. Слайсер загружает плагин. По пункту меню «Открыть StereotechAI» `agent/sidecar.py` выбирает свободный порт, создаёт секрет сессии и запускает `runtime\python\python.exe -m uvicorn src.backend.api.app:create_app --factory`.
2. При старте приложение создаёт недостающие таблицы (в том числе `queued_messages` и `task_queue`), загружает `knowledge/catalog.json`, запускает исполнитель очереди и отвечает на `GET /api/v1/health`.
3. Плагин строит одноразовую ссылку и открывает браузер с чатом.
4. Приложение само вызывает плагин по `server.json` (слайсер на этом же компьютере), файлы обмениваются через `Documents\STE_AIAssistant`.
5. Приложение следит за процессом слайсера (`PARENT_PID`) и завершается вместе с ним.

Адрес API, модель и ключ вводятся в окне чата. Они лежат в `runtime\data\model.json` и действуют со следующего вызова модели, без перезапуска.

## Чем отличается от прежней версии на Docker

- SQLite (режим WAL) вместо Postgres. Каждая транзакция сразу берёт блокировку записи, поэтому параллельные чаты ждут друг друга, а не падают.
- Очередь внутри процесса вместо Procrastinate. Строка в `task_queue` (задача, её аргументы и замок) пишется в той же транзакции, что и состояние задания. Этапы одного задания идут под замком `job:<id>` по одному и по порядку. Доставка сообщений из очереди чата, которую запускает отправка сообщения или «Скорректировать», идёт под своим замком `steer:<id>`: рядом с этапом, но не больше одной на задание. Всего одновременно идёт не больше `WORKER_CONCURRENCY` задач (по умолчанию 4). Новая ревизия отменяет ждущие этапы прежней, доставку она не отменяет.
- Работа, прерванная закрытием слайсера, при следующем старте запускается заново: обработчики идемпотентны. Сообщения, которые прерванная доставка успела взять, снова доступны для доставки через две минуты.
- События чата, включая события агентов и очереди сообщений, передаются через объект в памяти, а не через `LISTEN/NOTIFY`.
- Миграций нет: недостающие таблицы создаются при старте, существующие не меняются.
- Превью STL рисуется Pillow, а не matplotlib. Картинка та же по смыслу: три проекции с затенением.
- Docker и compose-файлов больше нет.

## Сборка

```
uv run python scripts/build_portable.py            # собирает фронтенд и архив
uv run python scripts/build_portable.py --skip-web # использовать готовый src/web/dist
```

Скрипт скачивает Python 3.11 embeddable и колёса под `win_amd64` (нужен интернет на машине сборки, не у жюри), проверяет синтаксис плагина под Python 3.5, целостность архива и его состав: в нём должны быть промпты агентов, таблицы подбора, знания и собранный чат, и не должно быть `.env`, баз, `model.json`, compose- и Docker-файлов. Результат: `dist/AIAssistant-portable.zip`.

На Mac, если Python не видит сертификаты, задайте `SSL_CERT_FILE` из `certifi`:

```
SSL_CERT_FILE=$(uv run python -c "import certifi; print(certifi.where())") uv run python scripts/build_portable.py
```

## Запуск из исходников без плагина

```
python3 scripts/bootstrap.py         # создаёт .env с SESSION_SECRET
uv sync --locked
uv run uvicorn src.backend.api.app:create_app --factory --port 8000
python3 scripts/bootstrap.py local   # печатает одноразовую ссылку для входа
```

`QWEN_API_KEY` в `.env` можно не заполнять: адрес API, модель и ключ вводятся в окне чата. Без слайсера, например на Mac, его заменяет `scripts/fake_ste_slicer.py`.

Тесты идут на SQLite и Postgres не требуют: `uv run --locked pytest -m "not live"`.
