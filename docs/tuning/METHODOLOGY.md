# Методология подбора параметров печати (этап 2)

Как `select_parameters` (`src/backend/tuning/select.py`) превращает карточку этапа 1 `TaskCard` 2.0 и, во втором заходе, обратную связь этапа 3 `stage3.feedback` 0.1 в `stage2.parameter_set` 0.2 для **Stereotech Hybrid 530 V5.2.4** (`hte530v5.2.4`). Здесь описано, что вычисляется, из каких полей входа и по какому правилу. Поля выхода и обратной связи заданы моделями `src/backend/domain/parameters.py` и схемами [parameter-set-v0.2](../parameter-set-v0.2.schema.json) и [stage3-feedback-v0.1](../stage3-feedback-v0.1.schema.json), решения — в [DECISIONS.md](DECISIONS.md).

```python
select_parameters(card: TaskCard, catalog: Catalog, keys: RequirementKeys, feedback: Feedback | None = None) -> ParameterSet
```

`catalog` — каталог выданной сборки `knowledge/ste_5.2.4` (`infrastructure/catalog.py`), его же читает проверка этапа 3. `keys` — общий с этапом 1 словарь кодов требований `knowledge/requirement_keys.json`. Ошибки входа — `AppError` с кодом (`card_blocked`, `card_schema`, `stl_report_missing`, `feedback_iteration`, `material_without_temperature` и другие).

Метки знаний:
- **D** — определения и код STE Slicer: ресурсы выданной сборки 5.2.4, плагины `StartSliceJob`;
- **S** — спецификация задачи;
- **G** — общая практика печати, на эталонах не проверена;
- **H** — гипотеза.

Эталонов жюри нет, поэтому качество значений не измерено (раздел 6).

## 0. Конвейер

```
TaskCard 2.0 [+ stage3.feedback 0.1]
  │ 1. приём: готовность, требования по общему словарю, свободный текст, геометрия STL   (intake.py, geometry.py)
  │ 2. материал: из карточки, ответа или ограничения, иначе ранжирование каталога 1,75 мм (material_choice.py, ranking.py)
  │ 3. факты и правила: сработавшие правила по фактам                                   (facts.py, rules.py, rules.json)
  │ 4. режим печати: голоса правил и ограничения, отсев по габаритам                     (mode.py)
  │ 5. план: сдвиги и жёсткие пределы осей, дискретные значения                          (axes.py, planning.py)
  │ 6. ограничения этапа 3 (заход 2): пределы осей, значения, ключи вне модели           (constraints.py)
  │ 7. профиль качества → значения от старта слайсера → отличия                          (quality.py, settings.py)
  │ 8. модель, допущения с id, статус                                                    (placement.py, output.py)
  ▼
ParameterSet 0.2
```

Каждый шаг — чистая функция с неизменяемым результатом и причинами. Порядок шагов виден в `select.py`. Данные принтера берутся из каталога (`printer.py`), правила, пространство поиска, свойства полимеров и фразы свободного текста лежат в JSON рядом с кодом и проверяются pydantic при импорте.

**Ось t.** У каждого непрерывного или порядкового параметра есть ось `t ∈ [0, 1]`: 0 — дёшево, быстро, хрупко; 1 — дорого, медленно, прочно. Значение `v = квантование(v0 + t · (v1 − v0))` по шагу оси. Округление банковское: 7,5 шага → 8.

**Старт — значение слайсера.** Это то, что слайсер взял бы сам: профиль качества, файл материала или определение сборки. Затем:
1. старт приводится в жёсткие пределы `[lo, hi]` (правила `limit`/`bound`, ограничения этапа 3);
2. складываются сдвиги `shift` сработавших правил;
3. результат снова приводится в пределы.

Если итог совпал со стартом, ключ **не отправляется**. Если `lo > hi` — конфликт: `infeasible`, пара требований или ограничений в `unsatisfied`. Если границу за пределы оси вынесло одно ограничение, в `unsatisfied` попадает оно одно.

**Источник значения** (`source`) определяется так:
- предел, который обрезал сдвиг;
- иначе последнее правило сдвига;
- иначе предел, сдвинувший старт.

`why` — тексты этих правил на русском.

**Что включает правила:**
- первый приоритет (`strength` / `speed` / `accuracy` / `cost`) — **только первый**;
- нагрузка `part.load`;
- требования `req.<код>` / `reqhard.<код>`;
- `pref.supports_allowed`, `pref.printing_mode`, `pref.quantity`;
- факты материала `material.speed`, `material.cooling_pct`;
- геометрия: `geometry.needs_repair`, `geometry.min_wall_estimate_mm`, `geometry.volume_mm3`, `geometry.surface_area_mm2`. Доли нависаний в отчёте STL нет, поэтому правила по нависаниям не срабатывают.

## 2. Параметры по отдельности

Пример — шестерня из эталона `tests/fixtures/tuning/gear`:
- требования: `tg_min_c` «85–90» °C, `high_stiffness` обязательна, `load_bearing` «Циклическая нагрузка»;
- пожелание «Важна прочность, затем точность»;
- выбран материал `enduse_pc`: 280 °C, 40 мм/с, обдув 0.

### 2.1 `printing_mode`
- **Голоса:**
  - `MODE-DEFAULT-CLASSIC` — 1;
  - `MODE-CARD-HINT` (требование `printing_mode`) — 10, `source: requirement:printing_mode`;
  - ограничение этапа 3 `printing_mode eq` — 1000;
  - `MODE-OVERHANG-5D` (нависания > 0,05 и жёсткий запрет поддержек → `cylindrical`) — 2 (H).
- **Отсев:** голос не считается, если режим запрещён ограничением или деталь не помещается «как загружено». Область берётся из каталога (D):
  - в 3D это X ≤ 320 мм рабочей области (стол 351 мм без запретных полос `machine_disallowed_areas`), Y ≤ 300,3, Z ≤ 300;
  - в 5D — прямоугольник детали внутри эллипса 351 × 300,3 (`machine_shape: elliptic`) и Z ≤ 231,1.
- **Победитель** — наибольшая сумма весов. Отклонённая просьба о режиме записывается в допущения. Если не подошёл ни один голос → `classic`, `infeasible`, `unsatisfied: GEOMETRY` со списком режимов, куда деталь поместилась бы.
- Режим выбирается сразу после материала: голосам нужны только сработавшие правила, а осям и профилям нужны значения сборки в выбранном режиме.
- **Шестерня:** `classic`, `rule:MODE-DEFAULT-CLASSIC`.

### 2.2 Материал
- **Материал назван** и найден по id или названию среди материалов 1,75 мм. Источники:
  - подтверждённое требование `material`, `source: requirement:<id>`;
  - ответ на вопрос `material_choice`, `source: requirement:answer.material_choice`;
  - ограничение `material eq`, `source: constraint:<id>`.

  Найденный материал проверяется по требованиям.
- **Иначе ранжирование пула** `enduse_*`, `fiberpart_*`, `sealant_*`, `generic_*` (кроме PVA):
  - статусы: `ok` 1, `warn` 0,4, `unknown` 0,3, `fail` 0;
  - вес: жёсткое требование 3, мягкое 1;
  - порядок: меньше провалов жёстких → выше оценка → id;
  - источник `rule:MATERIAL-RANK`, две альтернативы.
- **Конфликты.** Жёсткое требование, которое никто не выполняет, и пары таких требований дают `infeasible`. `unknown` и `warn` жёстких требований записываются в допущения.
- **Файл без температуры печати** пропускается с предупреждением. Если такой материал назван, подбор останавливается с ошибкой `material_without_temperature`.
- **Знание:** плотность, температуры, скорость, описание — файлы сборки через `Catalog.materials` (D). Tg, гигроскопичность, УФ, жёсткость, трение, износ — `traits.json` (G).
- **Шестерня:** `enduse_pc`, оценка 1,00 (Tg 147, жёсткость high); альтернативы `fiberpart_abs_g13`, `fiberpart_pc_g20`.

### 2.3 `quality_type` (и `layer_height`)
- **Ось:** 0,32 (0,8 · сопло, D) → 0,06 мм. Старт — слой профиля по умолчанию `normal` (0,1 мм; `preferred_quality_type` из метаданных `fdmprinter`, единственное значение принтера в `printer.json`).
- **Пределы:**
  - `LAYER-MAX-NOZZLE` ≤ 0,32 (D);
  - `LAYER-MIN-010` ≥ 0,1 (S);
  - `TOL-HARD-FINE-LAYER` (жёсткий допуск ≤ 0,15 мм) ≤ 0,15;
  - `NO-LAYERS-HARD` ≤ 0,1;
  - ограничения этапа 3 на `layer_height`.
- **Сдвиги:** `PRIORITY-SPEED` −0,25, `PRIORITY-ACCURACY` +0,25, `TOL-SOFT-FINE-LAYER` +0,2, `NO-LAYERS-SOFT` +0,3.
- **Выбор профиля.** Целевой слой → ближайший профиль каталога, чей слой в пределах: `high` 0,06, `normal` 0,1, `fast` 0,15, `draft` 0,2, `verydraft` 0,3. Профиль без своего слоя печатает слоем сборки. Профиль задан ограничением `quality_type` → он. Ни один профиль не в пределах → ближайший + явный `layer_height`. Совпал с `normal` → `source: default`.
- **Пример:** приоритет скорости: 0,1 → t 0,846 − 0,25 → 0,165 мм → `fast` (0,15) (эталон `speed`).
- **Шестерня:** `normal` (`default`): приоритет прочности слой не двигает.

### 2.4 `wall_thickness`
- **Ось** — число периметров 2 → 6, шаг 1. Отправляется толщина `n · ширина линии` (0,4 мм, `line_width` сборки). Формула слайсера `wall_line_count = round((t − 0,4)/0,4) + 1` (D) возвращает n.
- **Старт** — периметры из `wall_thickness` профиля (у `fast` 1 мм → 2 линии) или сборки (0,8 → 2).
- **Пределы:** `WALLS-MIN-2` ≥ 2 (S), `STIFF-HARD` ≥ 4, `FLEX-SOFT-STRUCTURE` ≤ 4, ограничения на `wall_thickness` / `wall_line_count`.
- **Сдвиги:** `PRIORITY-STRENGTH` +0,25 (+1 периметр), `LOAD-WALLS` +0,25 (циклическая / ударная), `STIFF-SOFT` +0,25.
- **Шестерня:** старт 2 → предел 4 → +0,25 +0,25 → 6 периметров, `wall_thickness` 2,4 мм.

### 2.5 `top_bottom_thickness`
- **Ось:** 0,8 → 2,0 мм, шаг 0,1. Старт 0,8 (сборка). `top_layers` / `bottom_layers` слайсер считает сам как `ceil(толщина / слой)`.
- **Предел `SKIN-MIN-3-LAYERS`:** не меньше 3 слоёв (S). Если толщина меньше 3 · слой, она поднимается до ближайшего шага.
- **Сдвиги:** `PRIORITY-STRENGTH` +0,25, `LOAD-WALLS` +0,1.
- **Шестерня:** t 0,35 → 1,22 → 1,2 мм (12 слоёв по 0,1).

### 2.6 `infill_sparse_density`
- **Ось:** 10 → 60 %, шаг 5. Старт — профиль (`fast` 10 %) или сборка (20 %).
- **Пределы:** `STIFF-HARD` ≥ 30, `FLEX-SOFT-STRUCTURE` ≤ 35, ограничения.
- **Сдвиги:** `PRIORITY-STRENGTH` +0,2, `PRIORITY-SPEED` −0,1, `PRIORITY-COST` −0,1, `STIFF-SOFT` +0,1.
- **Шестерня:** старт 20 % → предел 30 % (t 0,4) → +0,2 → **40 %**.

### 2.7 `infill_pattern`
- `INFILL-GYROID`: ударная или циклическая нагрузка либо гибкость → `gyroid` (G).
- Иначе формула сборки `infill_pattern` (D): `lines` при плотности > 25 %, иначе `grid`. Формула считается по выбранной плотности. Отправляется только отличие от формулы.
- Ограничения `eq/ne/in` выбирают из `grid, lines, gyroid, triangles, cubic, concentric`.
- **Шестерня:** **gyroid**.

### 2.8 `material_print_temperature`
- **Ось:** T−10 → T+10 °C от `print temperature` файла материала, шаг 5. Старт T. `scope: extruder:0`.
- **Пределы:** `TEMP-MATERIAL-WINDOW` (±10; S, DECISIONS), `TEMP-MACHINE-MAX` ≤ max(285, T), где 285 — `maximum_value_warning` сборки (D).
- **Сдвиг:** `PRIORITY-STRENGTH` +0,25 (+5 °C для спекания слоёв, G).
- **Шестерня:** 280 → **285 °C**, это же предел принтера.

### 2.9 `speed_print`
- **Ось:** 60 мм/с (сборка) → ½ · min(V, 60), шаг 5. V — `speed print` файла материала. Слайсер его не применяет: в `XmlMaterialProfile` нет сопоставления (D). От `speed_print` формулами считаются `speed_*_classic` / `_cylindrical`.
- **Пределы:** `SPEED-MATERIAL-MAX` ≤ V, `TOL-HARD-FINE-LAYER` t ≥ 0,4, `FLEX-SOFT-STRUCTURE` t ≥ 0,5.
- **Сдвиг:** `PRIORITY-ACCURACY` +0,3.
- **Примеры:** PETG (V = 45) → 45 мм/с, `rule:SPEED-MATERIAL-MAX`. **Шестерня** (V = 40) → 40 мм/с.

### 2.10 `material_bed_temperature`, `cool_fan_speed`, `cool_fan_enabled_<режим>`
- **Температура стола и скорость обдува** — значения файла материала, слайсер берёт их сам (`default_material_bed_temperature`, `cool_fan_speed`, D). Не отправляются. В 5D стол не греется (`machine_heated_bed`), температура стола там не отправляется никогда.
- **`FAN-OFF-NO-COOLING`:** обдув 0 % в файле → `cool_fan_enabled_classic` (3D) или `cool_fan_enabled_cylindrical` (5D) = `false`, `scope: extruder:0`. Ключ режима (`mode_keys` в `search_space.json`) нужен, потому что у `cool_fan_enabled` ключи режима не связаны с общим формулой (D).
- **Шестерня:** `cool_fan_enabled_classic` = false.

### 2.11 `retraction_enable`
- Значение сборки `true`. Длину и скорость отката задаёт файл материала (D). Отправляется только по ограничению этапа 3.

### 2.12 Поддержки: `support_enable`, `support_type`, `support_angle`, `support_enable_top_support`
- **`SUPPORT-OVERHANG`:** доля нависаний > 0,05 (S «> 45°»; порог G), поддержки разрешены, нет жёсткого запрета → `support_enable = true`. Отправляется общий ключ: `support_enable_classic` / `_cylindrical` следуют формулой (D).
- **`SUPPORT-FORBIDDEN-OVERHANG`:** нависания есть, поддержки запрещены → `unsatisfied: no_supports`.
- **Сейчас** нависаний во входе нет, поэтому `support_enable` остаётся `false` с допущением в ответе. `support_type`, `support_angle`, `support_enable_top_support` — значения сборки.

### 2.13 `adhesion_type`
- Формула сборки (D, 5.2.4): `brim` в 3D и 5D Spiral, `raft` в `cylindrical_full`. Правил нет, отправляется только по ограничению.

### 2.14 5D-ключи
- **Диаметр основания.** `cylindrical_mode_base_diameter` — диаметр цилиндра, которым слайсер режет модель в 5D: внутри 3D, снаружи 5D, `StartSliceJob` (D). Где он действует, видно по условию `enabled` в сборке. Вместе с `non_printing_base_diameter` он должен зависеть от диаметра отверстия детали. Его во входе нет, поэтому остаются 6 мм сборки с допущением в ответе. В тестовых G-code Stereotech — 10–20 мм.
- **Формулы сборки:** `cylindrical_layer_height` (= `layer_height`), `support_enable_cylindrical` (= `support_enable`), `cylindrical_raft_thickness`, `cylindrical_raft_diameter`.
- **Значения сборки:** `cylindrical_layer_height_0` 0,3, `cylindrical_raft_type` solid, `cylindrical_raft_base_height` 15.

### 2.15 Модель: `rotation`, `position`, `scale`
- `rotation` — единичная матрица («как загружено»), `scale` [1, 1, 1].
- `position`: центр рабочей области. В 3D x = (−169,5 + 150,5)/2 = −9,5 по запретным полосам `machine_disallowed_areas` (D), y = 0. В 5D полос нет, это ось вращения (0, 0). z — половина высоты модели.
- Источник — допущение об ориентации. Кандидат ориентации `o1`; исключение `o1` этапом 3 записывается в `unsatisfied`.
- **Шестерня:** `[−9,5, 0, 10]` для куба 20 мм эталона.

## 3. Второй заход (ограничения этапа 3)

Ограничение на ось → жёсткий предел оси (`limit_axis`). Затем тот же расчёт: старт → пределы → сдвиги → пределы.
- **Пример:** `infill_sparse_density max 25` у сильной детали → 25 %, `source: constraint:C1` (эталон `strong-limits`).
- **Ограничения на выбор** (режим, профиль, материал), дискретные значения (`eq` / `ne` / `in`) и ключи вне модели (передаются как есть) применяются напрямую.
- **Итог по каждому ограничению** — в `applied_constraints`: `applied` или `not_applied` с причиной. Третьего захода нет: обратная связь на заход 2 отклоняется ошибкой `feedback_iteration`.

## 4. Проверка и статус

Тест `hard_rule_violations` (`tests/backend/tuning/test_parameter_set_classic.py`) независимо проверяет готовый набор во всех трёх режимах:
- слой ≤ 0,8 · сопло;
- периметров ≥ 2;
- слоёв кожи ≥ 3;
- температура в окне материала и ≤ max(285, T);
- нет температуры стола в 5D;
- пруток материала = пруток экструдера.

`status`:
- `infeasible` — конфликт требований / ограничений или деталь не помещается в режим;
- иначе `proposed`.

`assumptions` с id `A1…` содержат:
- допущения этапа 1 и выводы при чтении карточки (`basis: карточка этапа 1`);
- допущения этапа 2: ориентация, партия, диаметр основания, требования-допущения, непроверенные свойства материала (`basis: решение этапа 2`).
