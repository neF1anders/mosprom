# Методология подбора параметров печати (этап 2)

Как `select_parameters` превращает карточку этапа 1 (и, во втором заходе, обратную связь этапа 3) в `stage2.parameter_set` v0.1 для **Stereotech Hybrid 530 V5.2.4** (`hte530v5.2.4`). Здесь описано, что вычисляется, из каких полей входа и по какому правилу. Поля — в [CONTRACTS.md](CONTRACTS.md), решения — в [DECISIONS.md](DECISIONS.md).

Метки знаний:
- **D** — определения и код STE Slicer: ресурсы выданной сборки 5.2.4, плагины `StartSliceJob`;
- **S** — спецификация задачи;
- **G** — общая практика печати, на эталонах не проверена;
- **H** — гипотеза.

Эталонов жюри нет, поэтому качество значений не измерено (раздел 6).

## 0. Конвейер

```
{idempotency_key, card v1.1} [+ stage3.feedback]
  │ 1. приём: готовность, card_ref, требования по словарю, геометрия из отчёта STL      (intake/)
  │ 2. материал: из карточки / ответа / ограничения или ранжирование каталога 1,75 мм   (material_choice.py)
  │ 3. правила: по фактам — сдвиги и жёсткие пределы осей, дискретные значения, голоса режима (rules.json, planning.py)
  │ 4. ограничения этапа 3 (заход 2): пределы осей, значения, выбор                      (constraints.py)
  │ 5. режим печати → профиль качества → значения от старта слайсера → отличия           (decisions.py)
  │ 6. модель, допущения с id, статус                                                    (decisions.py, output.py)
  ▼
stage2.parameter_set v0.1
```

**Ось t.** У каждого непрерывного или порядкового параметра есть ось `t ∈ [0, 1]`: 0 — дёшево, быстро, хрупко; 1 — дорого, медленно, прочно. Значение `v = квантование(v0 + t · (v1 − v0))` по шагу оси. Округление банковское: 7,5 шага → 8.

**Старт — значение слайсера.** Это то, что слайсер взял бы сам: профиль качества, файл материала или определение. Затем:
1. старт приводится в жёсткие пределы `[lo, hi]` (правила `limit`/`bound`, ограничения этапа 3);
2. складываются сдвиги `shift` сработавших правил;
3. результат снова приводится в пределы.

Если итог совпал со стартом, ключ **не отправляется**. Если `lo > hi` — конфликт: `infeasible`, пара требований / ограничений в `unsatisfied`.

**Источник значения** (`source`) определяется так:
- предел, который обрезал сдвиг;
- иначе последнее правило сдвига;
- иначе предел, сдвинувший старт.

`why` — тексты этих правил на русском.

**Что включает правила:**
- первый приоритет (`strength` / `speed` / `accuracy` / `cost`) — **только первый**;
- нагрузка `part.load`;
- требования `req.<key>` / `reqhard.<key>`;
- `pref.supports_allowed`, `pref.printing_mode`;
- факты материала `material.speed`, `material.cooling_pct`;
- геометрия.

## 1. Сводка: параметр → алгоритм

Набор: 20 названий в 3D, 29 в 5D. Отправляются только отличия: в 5D — не больше 25.

|---|---|---|---|---|
| `printing_mode` | требование `printing_mode`; ограничение этапа 3; габариты | голосование: classic 1, карточка 10, ограничение 1000, гипотеза 5D 2; режим, где деталь не помещается, исключается | всегда | S, D, H |
| материал `materials.0` | `material` / `answers.material_choice` / ограничение; требования к материалу | назван и найден → он; иначе ранжирование пула 1,75 мм | всегда | D, G |

## 2. Параметры по отдельности

Пример — шестерня из `stage1_example.json`:
- требования: Tg «85–90» °C, жёсткость обязательна, циклическая нагрузка, температура эксплуатации до 70 °C, допуск 0,15 мм (допущение);
- приоритет «прочность, затем точность»;
- материал `fiberpart_abs_g13`: 270 °C, 60 мм/с, обдув 0.

### 2.1 `printing_mode`
- **Голоса:**
  - `MODE-DEFAULT-CLASSIC` — 1;
  - `MODE-CARD-HINT` (требование `printing_mode`) — 10, `source: requirement:printing_mode`;
  - ограничение этапа 3 `printing_mode eq` — 1000;
  - `MODE-OVERHANG-5D` (нависания > 0,05 и жёсткий запрет поддержек → `cylindrical`) — 2 (H).
- **Отсев:** голос не считается, если режим запрещён ограничением или деталь не помещается «как загружено». В 3D это X ≤ 320 мм рабочей области, Y ≤ 300,3, Z ≤ 300. В 5D — прямоугольник детали внутри эллипса 351 × 300,3 и Z ≤ 231,1 (D).
- **Победитель** — наибольшая сумма весов. Отклонённая просьба о режиме записывается в допущения. Если не подошёл ни один голос → `classic`, `infeasible`, `unsatisfied: GEOMETRY` со списком режимов, куда деталь поместилась бы.
- **Шестерня:** `classic`, `rule:MODE-DEFAULT-CLASSIC`.

### 2.2 Материал
- **Материал назван** (требование `material`, подтверждённое; `answers.material_choice`; ограничение `material eq`) и найден по id или названию среди материалов 1,75 мм → берём его, проверяем по требованиям. Источник: `requirement:<id>` / `constraint:<id>`.
- **Иначе ранжирование пула** `enduse_*`, `fiberpart_*`, `sealant_*`, `generic_*` (кроме PVA):
  - статусы: `ok` 1, `warn` 0,4, `unknown` 0,3, `fail` 0;
  - вес: жёсткое требование 3, мягкое 1;
  - порядок: меньше провалов жёстких → выше оценка → id;
  - источник `rule:MATERIAL-RANK`, две альтернативы.
- **Конфликты.** Жёсткое требование, которое никто не выполняет, и пары таких требований дают `infeasible`. `unknown` и `warn` жёстких требований записываются в допущения.
- **Знание:** плотность, температуры, скорость, описание — файлы сборки (D). Tg, гигроскопичность, УФ, жёсткость, трение, износ — `traits.json` (G).
- **Шестерня:** `fiberpart_abs_g13`, оценка 1,00; альтернативы `enduse_abs`, `enduse_pc`.

### 2.3 `quality_type` (и `layer_height`)
- **Ось:** 0,32 (0,8 · сопло, D) → 0,06 мм. Старт — слой профиля по умолчанию `normal` (0,1 мм; `preferred_quality_type`, D).
- **Пределы:**
  - `LAYER-MAX-NOZZLE` ≤ 0,32 (D);
  - `LAYER-MIN-010` ≥ 0,1 (S);
  - `TOL-HARD-FINE-LAYER` (жёсткий допуск ≤ 0,15 мм) ≤ 0,15;
  - `NO-LAYERS-HARD` ≤ 0,1;
  - ограничения этапа 3 на `layer_height`.
- **Сдвиги:** `PRIORITY-SPEED` −0,25, `PRIORITY-ACCURACY` +0,25, `TOL-SOFT-FINE-LAYER` +0,2, `NO-LAYERS-SOFT` +0,3.
- **Выбор профиля.** Целевой слой → ближайший профиль, чей слой в пределах: `high` 0,06, `normal` 0,1, `fast` 0,15, `draft` 0,2, `verydraft` 0,3. Профиль задан ограничением `quality_type` → он. Ни один профиль не в пределах → ближайший + явный `layer_height`. Совпал с `normal` → `source: default`.
- **Пример:** приоритет скорости: 0,1 → t 0,846 − 0,25 → 0,165 мм → `fast` (0,15).
- **Шестерня:** `normal` (`default`): сдвиг на тонкий слой упёрся в предел 0,1 мм.

### 2.4 `wall_thickness`
- **Ось** — число периметров 2 → 6, шаг 1. Отправляется толщина `n · 0,4 мм`: формула слайсера `wall_line_count = round((t − 0,4)/0,4) + 1` (D) возвращает n.
- **Старт** — периметры из `wall_thickness` профиля (у `fast` 1 мм → 2 линии) или определения (0,8 → 2).
- **Пределы:** `WALLS-MIN-2` ≥ 2 (S), `STIFF-HARD` ≥ 4, `FLEX-SOFT-STRUCTURE` ≤ 4, ограничения на `wall_thickness` / `wall_line_count`.
- **Сдвиги:** `PRIORITY-STRENGTH` +0,25 (+1 периметр), `LOAD-WALLS` +0,25 (циклическая / ударная), `STIFF-SOFT` +0,25.
- **Шестерня:** старт 2 → предел 4 → +0,25 +0,25 → 6 периметров, `wall_thickness` 2,4 мм.

### 2.5 `top_bottom_thickness`
- **Ось:** 0,8 → 2,0 мм, шаг 0,1. Старт 0,8 (определение). `top_layers` / `bottom_layers` слайсер считает сам как `ceil(толщина / слой)`.
- **Предел `SKIN-MIN-3-LAYERS`:** не меньше 3 слоёв (S). Если толщина меньше 3 · слой, она поднимается до ближайшего шага.
- **Сдвиги:** `PRIORITY-STRENGTH` +0,25, `LOAD-WALLS` +0,1.
- **Шестерня:** t 0,35 → 1,22 → 1,2 мм (12 слоёв по 0,1).

### 2.6 `infill_sparse_density`
- **Ось:** 10 → 60 %, шаг 5. Старт — профиль (`fast` 10 %) или определение (20 %).
- **Пределы:** `STIFF-HARD` ≥ 30, `FLEX-SOFT-STRUCTURE` ≤ 35, ограничения.
- **Сдвиги:** `PRIORITY-STRENGTH` +0,2, `PRIORITY-SPEED` −0,1, `PRIORITY-COST` −0,1, `STIFF-SOFT` +0,1.
- **Шестерня:** старт 20 % → предел 30 % (t 0,4) → +0,2 → **40 %**.

### 2.7 `infill_pattern`
- `INFILL-GYROID`: ударная или циклическая нагрузка либо гибкость → `gyroid` (G).
- Иначе формула слайсера (D): `lines` при плотности > 25 %, иначе `grid`. Отправляется только отличие от формулы.
- Ограничения `eq/ne/in` выбирают из `grid, lines, gyroid, triangles, cubic, concentric`.
- **Шестерня:** **gyroid**.

### 2.8 `material_print_temperature`
- **Ось:** T−10 → T+10 °C от `print temperature` файла материала, шаг 5. Старт T. `scope: extruder:0`.
- **Пределы:** `TEMP-MATERIAL-WINDOW` (±10; S, DECISIONS), `TEMP-MACHINE-MAX` ≤ max(285, T) (D: `maximum_value_warning`).
- **Сдвиг:** `PRIORITY-STRENGTH` +0,25 (+5 °C для спекания слоёв, G).
- **Шестерня:** 270 → **275 °C**.

### 2.9 `speed_print`
- **Ось:** 60 мм/с (определение) → ½ · min(V, 60), шаг 5. V — `speed print` файла материала. Слайсер его не применяет: в `XmlMaterialProfile` нет сопоставления (D). От `speed_print` формулами считаются `speed_*_classic` / `_cylindrical`.
- **Пределы:** `SPEED-MATERIAL-MAX` ≤ V, `TOL-HARD-FINE-LAYER` t ≥ 0,4, `FLEX-SOFT-STRUCTURE` t ≥ 0,5.
- **Сдвиг:** `PRIORITY-ACCURACY` +0,3.
- **Примеры:** PA6 из сборки (V = 50) → 50 мм/с, `rule:SPEED-MATERIAL-MAX`. **Шестерня** (V = 60) — не отправляется.

### 2.10 `material_bed_temperature`, `cool_fan_speed`, `cool_fan_enabled_<режим>`
- **Температура стола и скорость обдува** — значения файла материала, слайсер берёт их сам (`default_material_bed_temperature`, `cool_fan_speed`, D). Не отправляются. В 5D стол не греется (`machine_heated_bed`), температура стола там не отправляется никогда.
- **`FAN-OFF-NO-COOLING`:** обдув 0 % в файле → `cool_fan_enabled_classic` (3D) или `cool_fan_enabled_cylindrical` (5D) = `false`, `scope: extruder:0`. Ключ режима нужен, потому что у `cool_fan_enabled` ключи режима не связаны с общим формулой (D).
- **Шестерня:** `cool_fan_enabled_classic` = false.

### 2.11 `retraction_enable`
- Значение слайсера `true`. Длину и скорость отката задаёт файл материала (D). Отправляется только по ограничению этапа 3.

### 2.12 Поддержки: `support_enable`, `support_type`, `support_angle`, `support_enable_top_support`
- **`SUPPORT-OVERHANG`:** доля нависаний > 0,05 (S «> 45°»; порог G), поддержки разрешены, нет жёсткого запрета → `support_enable = true`. Отправляется общий ключ: `support_enable_classic` / `_cylindrical` следуют формулой (D).
- **`SUPPORT-FORBIDDEN-OVERHANG`:** нависания есть, поддержки запрещены → `unsatisfied: no_supports`.
- **Сейчас** нависаний во входе нет, поэтому `support_enable` остаётся `false` с допущением в ответе. `support_type`, `support_angle`, `support_enable_top_support` — значения слайсера.

### 2.13 `adhesion_type`
- Значение режима (D, 5.2.4): `brim` в 3D и 5D Spiral, `raft` в `cylindrical_full`. Правил нет, отправляется только по ограничению.

### 2.14 5D-ключи
- **Диаметр основания.** `cylindrical_mode_base_diameter` — диаметр цилиндра, которым слайсер режет модель в 5D: внутри 3D, снаружи 5D, `StartSliceJob` (D). Вместе с `non_printing_base_diameter` он должен зависеть от диаметра отверстия детали. Его во входе нет, поэтому остаются 6 мм слайсера с допущением в ответе. В тестовых G-code Stereotech — 10–20 мм.
- **Формулы слайсера:** `cylindrical_layer_height` (= `layer_height`), `support_enable_cylindrical` (= `support_enable`), `cylindrical_raft_thickness`, `cylindrical_raft_diameter`.
- **Значения слайсера:** `cylindrical_layer_height_0` 0,3, `cylindrical_raft_type` solid, `cylindrical_raft_base_height` 15.

### 2.15 Модель: `rotation`, `position`, `scale`
- `rotation` — единичная матрица («как загружено»), `scale` [1, 1, 1].
- `position`: центр рабочей области. В 3D x = (−169,5 + 150,5)/2 = −9,5 (запретные полосы, D), y = 0. В 5D — ось вращения (0, 0). z — половина высоты модели.
- Источник — допущение об ориентации. Кандидат ориентации `o1`; исключение `o1` этапом 3 записывается в `unsatisfied`.
- **Шестерня:** `[−9,5, 0, 16,55]`: высота 33,1 мм по Z файла, то есть шестерня стоит на ребре. Нужен подбор ориентации.

## 3. Второй заход (ограничения этапа 3)

Ограничение на ось → жёсткий предел оси (`limit_param`). Затем тот же расчёт: старт → пределы → сдвиги → пределы.
- **Пример:** `infill_sparse_density max 30` у шестерни → 30 %, `source: constraint:C1`.
- **Ограничения на выбор** (режим, профиль, материал), дискретные значения (`eq` / `ne` / `in`) и ключи вне модели (передаются как есть) применяются напрямую.
- **Итог по каждому ограничению** — в `applied_constraints`: `applied` или `not_applied` с причиной (CONTRACTS.md, раздел 3). Третьего захода нет.

## 4. Проверка и статус

`hard_rules.py` независимо проверяет готовый набор:
- слой ≤ 0,8 · сопло;
- периметров ≥ 2;
- слоёв кожи ≥ 3;
- температура в окне материала и ≤ max(285, T);
- нет температуры стола в 5D;
- пруток материала = пруток экструдера.

`status`:
- `infeasible` — конфликт требований / ограничений или деталь не помещается в режим;
- иначе `proposed`.

`assumptions` с id `A1…` содержат:
- допущения этапа 1 (`basis: карточка этапа 1`);
- допущения этапа 2: единицы, нависания, ориентация, диаметр основания, требования-допущения, непроверенные свойства материала.

## 5. Расхождения с устройством: что исправлено

- **Исправлено:**
  - принтер 5.2.4 (стол 351, 5D 231,1, эллипс, запретные зоны);
  - профиль качества вместо дробного слоя;
  - исходные ключи вместо производных (`wall_thickness`, `top_bottom_thickness`, `support_enable`, `layer_height`);
  - `scope: extruder:0` у настроек экструдера;
  - нет температуры стола в 5D;
  - адгезия по режиму;
  - материалы только 1,75 мм;
  - положение модели.
- **Не исправлено (нет данных):** ориентация, поддержки по нависаниям, диаметр основания и плот 5D — ждут полей от этапа 1 (INTEGRATION.md, раздел 2).

## 6. Что проверено, а что нет

**Проверено:**
- выход проходит проверку этапа 3 `check_parameter_set.py` по ресурсам 5.2.4 без ошибок и предупреждений — на E2E-случаях 3D, 5D Spiral, 5D, второй заход и на шестерне с каталогом сборки;
- данные профиля сверены с ресурсами сборки (тест при `STE_RESOURCES_DIR`);
- вывод детерминирован;
- жёсткие правила не нарушаются (E2E).

**Не проверено:**
- что значения хороши: нет эталонов жюри и запуска слайсера;
- величины сдвигов правил и границы осей (G);
- свойства полимеров (G);
- выбор 5D (H);
- единицы при `unknown`;
- как адаптер применит набор в слайсере.
