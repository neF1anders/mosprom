# KB-001

Снимок профилей материалов из выданного исходного STE Slicer. Это значения конфигурации слайсера, а не подтверждение результатов испытаний конкретной партии материала.

`ste_5.2.4/` хранит файлы выданной сборки STE Slicer 5.2.4 для принтера Stereotech Hybrid 530 V5.2.4: цепочку определений (`hte530v5.2.4` → `steprinter530_v5.2.4` → `steprinter_v5` → `fdmprinter`), экструдеры, профили качества и все материалы сборки. Файлы взяты из ветки `fedor/validation-ste` без изменений. Из них строятся KB-001, подбор параметров и проверка набора. Файлы сборки не публикуются за пределами команды.

`catalog.json` проходит Pydantic-валидацию при импорте. SHA-256 исходного файла сборки включён в запись свойства. Единица плотности g/cm³ подтверждена интерфейсом исходного слайсера `resources/qml/Preferences/Materials/MaterialsView.qml:220` (`density-unit.md`).

Импорт: `python scripts/import_knowledge.py`. Повторный импорт идемпотентен. Сборка снимка из `ste_5.2.4/`: `python scripts/build_knowledge.py`.

Механические, химические и температурные характеристики, отсутствующие в этих источниках, не заполнены предположениями. Они требуют проверенных паспортов. Наличие профиля не гарантирует совместимость с каждым режимом Hybrid 530.

Семь исходных ТЗ используются как приёмочные примеры, а не как источник свойств материалов. Программа не обращается к веб-поиску при обработке задания.
