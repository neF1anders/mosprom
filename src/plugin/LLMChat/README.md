# LLMChat plugin for STE Slicer (hello world)

Install: copy the `LLMChat` folder into `<STE Slicer config dir>/plugins/` (the same place as other user plugins), restart the slicer, then open menu AI > Open chat.
Enter Base URL, API key and model from the organizers, press Save, send a message.
Keys are stored in the slicer preferences, never in the repo.
