# Контекст проекта: Mosprom Wiki (для продолжения в Claude Code)

Пользователь: Fedor, говорит по-русски. Стиль общения: коротко, по делу. Стиль сайта: сухо, без пафоса, простые слова, без сложных терминов.

## 1. Цель проекта
Хакатон. Нужен ИИ-надстройка над слайсером (FDM 3D/5D-печать): MCP-сервер с чатом. Пользователь даёт STL, фото и текстовый запрос. Сервис сам подбирает параметры печати, делает G-код, отправляет на нужный принтер из парка и следит за печатью.

Итоговый артефакт для пользователя: статичный сайт «Mosprom Wiki» на GitHub Pages. Он сам заливает файлы в корень репозитория (Settings → Pages → main → / (root), репозиторий публичный). После обновления: Ctrl+F5.

## 2. Что на сайте сейчас
Разделы меню: Задача, Архитектура, Этапы, Сборки, Источники.
- **Задача**: вход и выход, блок «Как считается оценка» (формула, веса, шкала, пороги), термины.
- **Архитектура**: 10 этапов (чат и связь с ИИ; получение 3D-модели; проверка и починка модели; подбор параметров; нарезка в G-код; проверка G-кода; отправка на принтер; несколько принтеров и очередь; наблюдение за печатью; 5D и непланарная печать), таблица этапов со статусом.
- **Этапы**: карточка этапа (название, статус, описание, вход и выход, строка «Всего найдено: N») и раскрывающаяся «Подробная статья: все найденные решения этапа (N)». Внутри только одна таблица: решения с оценкой по убыванию (первые три помечены «Топ 1–3»), ниже находки без оценки.
- **Сборки**: цельные сборки и конкуренты (11 + JusPrin + text-to-cad), плашка про обновление.
- **Источники**: фильтр, список ссылок (в т.ч. «добавлено 21.10»).

Что пользователь просил убрать (не возвращать): заголовок «Сравнение 35 компонентов», таблицу покрытия функций, таблицу всех компонентов, панели весов и рейтинга, отдельный раздел «Россия», раздел «Итоги по категориям», заголовок «Готовые решения», три карточки решений в этапах, «Ещё найдено: N», старый текст статьи в этапах. Правило: не добавлять новые разделы, только обновлять базу.

## 3. Формула оценки
Пять критериев, оценки 0–5 целые, субъективные (ставил я по прочитанным страницам).
Оценка = 0,30 × Покрытие кейса + 0,20 × Зрелость + 0,15 × Открытость и лицензия + 0,20 × Интегрируемость + 0,15 × Подтверждённость данных.
Пороги: ≥ 3,5 «Брать»; 2,5–3,5 «Рассмотреть или взять идею»; ниже «Только как референс». Ничья: по названию. Пример: Kiln [4,3,2,5,2] = 3,40.

## 4. Структура файлов (папка mosprom-src)
- `make_mosprom.py` — генератор сайта. Запуск: `python3 make_mosprom.py` (нужны `pip install markdown`). Пишет в `mosprom/`: index.html, data.js, README.md, .nojekyll. `style.css` и `app.js` лежат в `mosprom/` и правятся руками.
  - Читает `pages/data.js` (базовые 35 компонентов, 11 сборок, критерии, пороги).
  - Подмешивает `extra_data.py`, `extra_data2.py`, `extra_data3.py` (новые компоненты NEW/NEW2/NEW3, сборки NEWB, находки по этапам EXTRA/EXTRA2/EXTRA3, русские источники RUS, правки лицензий и описаний OVER, FIXCMU).
  - `detail1.py`, `detail2.py`, `detail3.py` — словари DET: для каждого из 104 компонентов три текста (что это, как пригодится у нас, ограничения). Ключ = точное название компонента. Новый компонент без записи в DET показывает только короткое описание `y`.
  - `site/wiki.md` — исходный текст вики (источники, сборки, статьи этапов, больше не показываются в этапах).
  - В генераторе: список ST (10 этапов с тремя «решениями этапа», сейчас на странице не показываются), STCAT (какие категории относятся к этапу), S5 (какие из «Слайсеры и API принтеров» относятся к этапу 5, остальные к этапу 7), `stage_items`, `stage_table`.
- `shot7.py` — Playwright-проверка (ошибки консоли, горизонтальная прокрутка на 1366 и 390 px). Запускает http.server на порту.
- `research5/known.txt` — список всех уже известных URL (282 строки) для дедупликации при новом поиске.
- `mosprom/` — готовый сайт.

Как добавить решение: добавить кортеж в NEW-список (формат `(name, category, [5 оценок], license, rationale, url)`), добавить запись в DET (три текста), при необходимости в EXTRA (находка без оценки: `(name, url, text, verified 0/1)` по номеру этапа). Затем `python3 make_mosprom.py`.

Категории компонентов: «Управление принтерами и слайсерами (MCP)», «Подбор параметров», «Мониторинг и дефекты», «Управление парком», «Генерация моделей», «Анализ и починка STL», «Слайсеры и API принтеров», «Каркас сервера», «5D и непланарная печать», «Проверка G-кода».

## 5. Содержимое базы (кратко)
162 компонента с оценками (104 + 58 из раунда 5 от 23.10) и 289 записей в списках находок; всего по этапам 1–10 найдено: 68, 49, 23, 69, 37, 27, 28, 28, 50, 20. Раунд 5b (23.10) собран тремя помощниками (реестры, форумы, статьи и наборы данных); звёзды, лицензии и даты из их отчётов сверялись через gh api и API arXiv/Hugging Face, записи без сверки помечены звёздочкой (ok=0). Новые компоненты лежат в `extra_data4.py` (NEW4, EXTRA4), описания в `detail4.py` (DET4). Проверка на 1366 и 390 px: `shot7.py` устарел (ищет `.catdet`, которого нет), использовалась упрощённая проверка: без ошибок консоли и без прокрутки вбок.

Главные выводы исследования:
- Ни одно найденное решение не закрывает всю цепочку. Ближе всего Kiln (широкая цепочка, AGPL, часть платная) и text-to-cad (текст/картинка → модель → Orca → Bambu).
- Подбор параметров по цели: ранние решения. JusPrin (форк OrcaSlicer с ИИ-чатом, бета, AGPL, кредиты), Creality Print 7.2 AI (бета, только Creality), SimplyPrint AI Expert mode (предрелиз), FabTally MCP (закрытый), PrusaMCP (recommend_profile, неактивный), CMU «LLM как эксперт» (код есть, лицензии нет, использовать нельзя без разрешения; метод можно реализовать по статье).
- Топ в категориях (по текущим оценкам): MCP — Clarvis AI 3,60 / mcp-3D-printer-server 3,60 / Kiln 3,40; Подбор — Strecs3D 3,30 / JusPrin 3,25 / CMU 2,75; Мониторинг — Obico 3,40 / OctoEverywhere AI API 3,05 / Additive-Manufacturing-Benchmark 3,00; Парк — Daedalus 3,50 / SimplyPrint 3,45 / FDM Monster 3,20; Генерация — text-to-cad 3,95 / CadQuery+LLM 3,70 / TRELLIS.2 3,45; STL — trimesh 4,25 / augura 3,70 / numpy-stl 3,45; API — Moonraker 4,25 / OctoPrint 4,25 / Duet 3,85; 5D — Fractal Cortex 3,60 / Pentos 3,10 / S4 Slicer 2,90; G-код — gcodeparser 3,50 / Kiln validate_gcode 3,35 / навык gcode (text-to-cad) 3,20.
