# mosprom

Команда хакатона: Макс, Элен, Юля, Федор и Григорий.

Концепция: ассистент-технолог для STE Slicer, который переводит условия эксплуатации детали в обоснованные настройки 3D/5D-печати и сохраняет воспроизводимые проекты 3MF и G-code.

- [Источники, ограничения и выводы исследования](docs/RESEARCH_NOTES.md)
- [Правила работы с Git и Pull Requests](CONTRIBUTING.md)
